🧠 Prepify – Smart Study Planner & Analytics System

Prepify is a Flask-based web application designed to help students plan, track, and optimize their study schedules efficiently. It combines task scheduling, analytics, and predictive insights to improve productivity and exam readiness.

🚀 Features
📅 Smart study plan generation
⏱️ Custom study time configuration
🔄 Auto-rescheduling of missed tasks
📊 Dashboard with progress tracking
📈 Subject-wise analytics
🔮 Syllabus completion prediction
⚠️ Exam overload warning system
📝 Bulk topic input (comma-separated)
🔐 User authentication system
💬 Flash messaging for feedback
🎯 Clean and unified UI
🛠️ Tech Stack
Frontend: HTML, CSS
Backend: Python (Flask)
Database: SQLite (SQLAlchemy ORM)
📂 Project Structure
Prepify/
│── static/          # CSS, JS, assets
│── templates/       # HTML files
│── app.py           # Main Flask app
│── models.py        # Database models
│── routes/          # Application routes
│── instance/        # Database files
⚙️ Installation & Setup

# Go to project folder
cd prepify

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
